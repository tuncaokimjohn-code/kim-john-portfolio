THE PROBLEM

Understand code before trusting it.

Modern applications can be assembled quickly, especially with AI coding tools. VibeFlow explores how to make a codebase easier to understand and possible security concerns easier to investigate, without running the repository's code.

What the prototype demonstrates

  • Read-only import of supported public GitHub TypeScript/TSX source at a fixed commit.
  • Interactive module and import-relationship visualization.
  • Conservative indicators for hardcoded credentials, dynamically constructed SQL, and unsafe dynamic HTML.
  • File-linked finding evidence and focused inspection.
  • Muse Spark explanations of selected findings and illustrative safer-code comparisons.
BUILD & VERIFICATION

Hackathon delivery.

My role: Project concept and scope, product direction, AI-assisted development coordination, acceptance criteria, testing oversight, quality reviews, demo preparation, and final submission.

Technical approach: Read-only source intake, static code inspection, evidence provenance, visual architecture exploration, and bounded AI-assisted explanations. The demo fixture contained 46 TypeScript/TSX modules with 113 static imports.

Evidence, not exaggerated claims

The public GitHub repository and recorded demonstration show the submitted prototype. This was an international hackathon participation project; no finalist placement, prize, or certificate is claimed.

Limitations: This is not a malware scanner, comprehensive vulnerability assessment, penetration-testing platform, or proof that any repository is safe. Detection coverage is limited, and not every explanation path succeeded during testing. AI output requires human review.

Project status: Hackathon completed; further development paused.
