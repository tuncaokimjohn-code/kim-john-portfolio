Example Bug Report

BUG-01 · MEDIUM

Mobile navigation stays open after destination is selected

Environment: Mobile viewport, modern Chromium browser

Steps: 1. Open navigation. 2. Select “Portfolio.” 3. Observe menu state.

Expected: Menu closes after navigation.

Actual: Menu remains over page content.

Recommendation: Add click handlers to navigation links that remove the open state and reset the expanded accessibility attribute.

Release after all medium or higher defects are resolved, critical user flows are retested, and responsive checks pass on representative mobile and desktop widths.
