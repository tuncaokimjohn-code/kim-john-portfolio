BUG-01 · MEDIUM · FICTIONAL CASE

Menu remains open after navigation

Steps: Open mobile menu → select Portfolio → observe menu state.

Expected: Menu closes. Actual: Menu remains over content.

Recommendation: Clear the menu's open class and update aria-expanded when a navigation item is clicked.

Release recommendation

Release only after medium-plus defects are resolved or properly accepted, critical workflows are retested, responsive layouts are checked and evidence is documented.
